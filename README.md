# 🚀 Modern Data Roadmap: De Ingestão a Analytics Engineering
Bem-vindo ao meu Roadmap de Engenharia de Dados. Este repositório documenta minha jornada técnica, dividida em três níveis de complexidade crescente, focada em construir pipelines de dados modernos, escaláveis e profissionais.

## 🗺️ Visão Geral do Roadmap
O projeto está estruturado para demonstrar competências em Python (OOP), SQL Avançado, Orquestração (Airflow) e Modelagem de Dados (dbt/Medallion Architecture).

## 📁 Nível 01: Fundamentos de Ingestão & SQL
Neste estágio inicial, o foco foi dominar a base da pirâmide de dados: a extração e a persistência.
- **O que fiz:** Ingestão de dados via scripts Python e modelagem relacional básica.
- **Destaque Técnico:** Criação de queries SQL para limpeza de dados e estruturação de tabelas no PostgreSQL.
- **Stack:** Python, SQL, PostgreSQL.
- [Acessar Nível 01 →](https://github.com/juniorsilvacc/modern-data-roadmap/tree/master/nivel-01)


## 📁 Nível 02: Automação & Containers
Aqui, o projeto evoluiu para o conceito de Infraestrutura como Código e automação de processos.
- **O que fiz:**
    - Containerização de toda a stack utilizando Docker. 
    - Implementação da orquestração de tarefas utilizando Python para garantir que os dados fossem processados de forma recorrente e automática. 
    - Criação de dashboards no Power BI para transformar dados processados em insights visuais.
- **Destaque Técnico:** Configuração de ambientes isolados e garantia de portabilidade do projeto (qualquer um pode rodar o projeto com um comando).
- **Stack:** Docker, Docker Compose, Python.
- [Acessar Nível 02 →](https://github.com/juniorsilvacc/modern-data-roadmap/tree/master/nivel-02)


## 📁 Nível 03: Modern Data Stack & Observabilidade
O nível mais avançado, transformando dados brutos em inteligência de negócio com rigor de Engenharia de Software.
- **O que fiz:** 
    - **Arquitetura Medallion:** Implementação das camadas Bronze, Silver e Gold para garantir governança e rastreabilidade.
    - **Ingestão & Orquestração:** Integração de API de Criptomoedas com fluxos automatizados via Apache Airflow.
    - **Analytics Engineering:** Modelagem dimensional e transformações robustas utilizando dbt, garantindo dados prontos para negócio.
    - **Observabilidade:** Configuração de monitoramento em tempo real com Grafana e Prometheus.
- **Destaque Técnico:** 46 testes automatizados, documentação de linhagem de dados, e monitoramento de infraestrutura com Grafana e Prometheus.
- **Stack:** dbt Core, Airflow, Docker, Grafana, PostgreSQL, Python (OOP).
- [Acessar Nível 03 →](https://github.com/juniorsilvacc/modern-data-roadmap/tree/master/nivel-03)
